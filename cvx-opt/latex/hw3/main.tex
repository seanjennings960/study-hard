A simple example of such a function is $f(x, y) = xy$. When each variable
is held fixed, $f$ is a linear function and therefore convex. Let
$z_1 = (x_1, y_1) = (0, 2)$ and $z_2 = (x_2, y_2) = (0, 2)$.
Since $f(z_1) = f(z_2) = 0$, while $f(\lambda z_1 + (1 - \lambda) z_2) = f(1, 1) = 1$ for $\lambda = 0.5$,
we have
\begin{equation}
    0 = \lambda f(z_1) + (1 - \lambda) f(z_2) < f(\lambda z_1 + (1 - \lambda) z_2) = 1
\end{equation}
showing that $f$ is not jointly convex.
